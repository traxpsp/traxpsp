The skin folder

Each skin is a folder inside SKINS, beside the TRAX app. skin.json is optional: without it the skin works but prints no text, since nothing in a picture says where a title should go.

PSP/GAME/musictest/SKINS/
  hub.png                    the reel hub every skin uses
  Maxell XLII 90/
    Maxell XLII 90.png       the picture
    skin.json                optional: the label and background
    hub.png                  optional: this skin's own hub

The picture is the PNG named after the folder. Failing that, TRAX uses skin.png, and failing that, the only other picture in the folder. Draw it at 480 × 272, the PSP's screen size, so it's shown pixel for pixel. Any other size is stretched to fit.

The picture is drawn over the turning reels. Wherever it's transparent, the reels, the tape and the background show through.

All positions in skin.json are screen pixels, measured from the top-left corner of that 480 × 272 picture.

A complete example

This is the file that ships with the Maxell XLII 90 skin, with the defaults written out:

{
  "name": "Maxell XLII 90",

  "background": {
    "colors": ["#1B0B3A", "#0B3A5C", "#0B5C3A"],
    "seconds": 6,
    "blend": "fade",
    "while": "playing"
  },

  "defaults": { "size": 14, "align": "left", "color": "#1E1E1E" },

  "areas": [
    {
      "rect": [62, 70, 263, 22],
      "size": 11,
      "align": "center",
      "lines": [ ["album", ": ", "artist"] ]
    }
  ]
}

Top level

The file is a JSON object. Every key is optional, and keys are case-sensitive. TRAX ignores keys it doesn't know.

KeyTypeMeaning
namestringThe skin's name. Reserved for now: the name TRAX shows when you switch skins comes from the folder.
backgroundcolor or objectWhat shows behind the cassette. See background.
defaultsobjectsize, align and color for every area that doesn't set its own. Any rect or lines here is ignored.
areasarrayWhere text is printed, and what. See areas.

background

The background fills the screen behind the reels. It shows wherever the skin's picture is transparent. Without one it's black.

Give it either a single color:

"background": "#0B3A5C"

or an object, to move between several colors:

KeyTypeDefaultMeaning
colorsarray of colorsnoneThe colors to move through, in order, then round again. Up to 6.
secondsnumber6How long each color takes to become the next, from 1 to 3600.
blend"fade" or "step""fade"fade blends smoothly from one color to the next. step changes all at once.
while"playing" or "always""playing"With playing, the first color shows whenever the music is paused or stopped. With always, the color it had reached stays.
The cycle follows the track, not a clock. It's timed by the playing position, so it starts again with each track, and scrubbing moves it forward or back with the music.

areas

Each area is a rectangle on the screen where lines of text are printed. A skin can have up to 8. An area uses the defaults for anything it doesn't set.

KeyTypeDefaultMeaning
rect[x, y, width, height]requiredThe area, in screen pixels. An area running off the screen is cut back to its edge. One with no width or height is skipped.
linesarraynoneThe lines of text, top to bottom. Up to 4. See lines and fields.
sizenumber14The height of the text, in pixels.
align"left", "center" or "right""left"Where each line sits across the area. Anything else means left.
colorcolorchosenThe text color. Leave it out and TRAX picks dark or light text to suit the picture. See Colors.

lines and fields

Each line is a list of pieces joined together. A piece that is exactly one of these words is replaced with information about what's playing:

FieldPrints
titleThe track's title.
artistThe track's artist.
albumThe track's album.
trackWhere you are in the queue, such as 3/12. In a shuffle mode this is the place in the play order.
playlistWhat you're playing through: the album when the track has one, otherwise the name of the track's folder.

Any other piece is printed as written, so "Side A · " stays as it is. Field names are lowercase and must match exactly: "Title" prints the word "Title".

A line with a single piece can be written as a plain string instead of a list:

"lines": [ "title", ["artist", " — ", "album"] ]

Missing information

A field the track has nothing for is left out, and so is any text that was only there to separate it. Text between two fields is kept only when both of them have something. Text before or after all the fields is kept only when the field beside it has something.

  • ["album", ": ", "artist"] with no artist prints just the album, without the colon.
  • ["Side A · ", "title"] with no title prints nothing.
  • A line that ends up empty is skipped.

How text is fitted

  • Placement: the lines are stacked as a block in the middle of the area, top to bottom, each size + 2 pixels below the last.
  • Too wide: a line that doesn't fit is first made smaller, up to three times, each step 12% smaller, to about two-thirds of size. If it still doesn't fit, it's cut short with "...".
  • Font: the text uses the PSP's own system font, as the rest of TRAX does. Accented, Japanese and Korean names all print.

Colors

Every color is written "#RRGGBB": a hash and exactly six hexadecimal digits, in upper or lower case. Short forms like "#FFF", names like "white" and transparency aren't supported. A color TRAX can't read is ignored, as if it weren't there.

When an area has no color, TRAX looks at the opaque parts of the picture inside the area. If they're light, the text is dark gray (#202020); if they're dark, it's near-white (#F0F0F0). The same text is readable on a white label and on a dark shell without you setting anything.

Limits

TRAX stops reading at each limit and ignores the rest, rather than rejecting the file.

WhatMost
Size of skin.json32 KB
Areas8
Lines in an area4
Pieces in a line6
Text in one piece47 bytes (fewer characters for accented or Japanese text)
Background colors6

If the file isn't valid JSON, the skin still loads, but with no text and a black background.

Testing a skin

  • TRAX reads skin.json each time a skin is chosen. After copying a changed file to the memory stick, press or in the Tape deck to move to another skin and back.
  • Try a track with no album or artist tags, to check the label still reads well when fields drop out.
  • Try a long title, to check it shrinks and is cut short neatly within its area.
  • Check the JSON with any validator first. A stray comma after the last item turns off all of the skin's text.
